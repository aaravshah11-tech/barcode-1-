First time on this device: trust HQ

Phones only let a web page use the camera and sensors over a secure connection. HQ makes its own security certificate, so this device needs to trust it once. About a minute.

⇩ Download HQ certificate

iPhone / iPad
  1. Tap Download HQ certificate above, then Allow (“…download a configuration profile”). Tap Close.
  2. Open the Settings app. Near the top tap Profile Downloaded → Install → enter your passcode → Install → Done.
  3. Still in Settings: General → About → Certificate Trust Settings → switch on SENTINEL Local CA → Continue.
  4. Come back to Safari and tap Done — continue below.
Android
  1. Tap Download HQ certificate above (Chrome saves SENTINEL-HQ.crt).
  2. Open Settings and search for “CA certificate” (usually Security → More security settings → Encryption & credentials → Install a certificate → CA certificate). Tap Install anyway and choose SENTINEL-HQ.crt from Downloads.
  3. Come back to Chrome and tap Done — continue below.
Computer / other
  1. Download the certificate and add it to the system’s trusted root certificates (Mac: double-click it → Keychain Access → Always Trust; Windows: open it → Install Certificate → Local Machine → Trusted Root Certification Authorities).
  2. Restart the browser and tap Done — continue.

This device still doesn’t trust HQ. Check the last step (switching the certificate on), then try again.

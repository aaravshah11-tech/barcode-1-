Operator’s Quick Reference

SENTINEL 4.0 · HQ = the HQ page open in Chrome on your Mac · keep this page by the desk.

Every day

  1. Open HQ in Chrome, sign in (codename + PIN, then the 6-digit code if 2FA is on).
  2. Read the Current Picture (top left of the Operations Floor).
  3. Set the Alert State in the top bar when it changes (SENTINEL suggests it).
  4. Clear Triage (3): every alert gets Acknowledge, Dismiss with a reason, or an Incident.
  5. Leave HQ open, the Mac plugged in and awake. Agents only report while HQ is open.

Alert States

HOMESomeone in. Activity is logged; nothing alarms.
AWAYNobody in. Any activity is an intrusion.
NIGHTAsleep. Agents marked “armed at night” alarm; bedrooms don’t.
LOCKDOWNEverything armed; Agents may sound the alarm. Panic = LOCKDOWN at once.

How serious is it?

INFOFor the record. No sound, doesn’t count as waiting.
ADVISORYWorth a look. One soft tone.
ALERTAct now. Two-tone and a notification.
CRITICALEmergency. Repeats until acknowledged — even in quiet hours.

Graded by context: what was seen, where, the Alert State, the wind and what is normal at that hour. Your own rules: Administration › Rules and patterns › Grading rules.

Agents (old phones)

  • Recruit (top bar) → scan the QR with the phone → pick its mission.
  • Keep it on a charger. The screen goes near-black after a minute; tap to wake.
  • The SENTINEL AGENT ACTIVE banner is always on screen.
  • “HQ OFFLINE – STANDING BY” = HQ is closed or the Wi-Fi dropped. It resumes by itself.
  • Outside / window phones: PERIMETER WATCH. Finish its setup wizard and mask anything that isn’t yours — it can’t alert until you do.
  • Find a phone: Agents › Registry › tick it › Identify.

The Analyst

  • Ask in plain English (8, or “Ask the Analyst” on the floor).
  • Every fact has a reference (ALT-…, INC-…, EVT-…): click it to see the evidence.
  • It can only suggest. Nothing happens until you press the button.
  • Not set up? You still get automatic summaries. Set up: Analyst › Set up.

Rules SENTINEL always keeps

  1. Camera and microphone data stays on the Agent — only events and numbers leave it.
  2. Every active Agent shows the “SENTINEL AGENT ACTIVE” banner.
  3. Outside Agents need privacy masks before they can be armed.
  4. The network check only looks at your own home network.
  5. The Analyst runs locally, only reads, cites evidence, changes nothing without you.
  6. All data stays on HQ, encrypted, deleted by the retention policy.
  7. No real agency or TV-show names or branding.
